# UniStudy AI — منصة الدراسة والامتحانات الجامعية الشخصية

منصة تعليمية جامعية شخصية متكاملة ومستقلة، تعمل على الموبايل والتابلت واللابتوب، وتعتمد على التخزين المحلي الآمن (`IndexedDB` عبر `Dexie.js`) دون الحاجة لخوادم خارجية في عمليات التخزين الأساسية، وتعمل دون اتصال بالإنترنت.

---

## 📌 مميزات المرحلة الثالثة المنجزة (بنك الأسئلة) وتحديثات المرحلة الثانية

1. **بنك الأسئلة المتكامل (`Question Bank`):**
   - إضافة الأسئلة يدوياً بأنواعها: **اختيار من متعدد (Multiple Choice)** و **صح أو خطأ (True / False)**.
   - التحقق الصارم من صحة الحقول (عدم ترك خيارات فارغة، اشتراط خيارين على الأقل، ومطابقة الإجابة الصحيحة).
   - خيارات متعددة مع تحديد الإجابة الصحيحة عبر زر راديو واضح.
   - تصنيف مستوى الصعوبة: **سهل**، **متوسط**، **صعب**.
   - إضافة شرح وتوضيح الإجابة الصحيحة للرجوع إليه أثناء المذاكرة والمراجعة.
   - ربط السؤال بالملف المصدر من المحاضرات (PDF) ورقم الصفحة أو الفقرة.
   - تصفية متقدمة حسب المادة، والوحدة، ونوع السؤال، ومستوى الصعوبة، والبحث الفوري في نص الأسئلة والخيارات والتعليلات.
   - إحصائيات حية لبنك الأسئلة وتوزيعه في لوحة التحكم وصفحة المادة.
   - دمج بنك الأسئلة داخل صفحة تفاصيل المادة كـ Tab مستقل يتيح إضافة ومراجعة أسئلة كل مادة مباشرة.

2. **إصلاح وتحسين رفع ملفات الـ PDF:**
   - حل مشكلة تكرار المحاولات عند اختيار الملفات: إعادة تعيين قيمة مدخل الملفات فوراً (`input.value = ''`) لدعم إعادة الاختيار السلس من المحاولة الأولى.
   - إضافة زر تصفح مباشر واضح مع معالجة أحداث السحب والإفلات (`Drag & Drop`) وتقديم مؤشر مرئي عند سحب الملفات.
   - عرض فوري للملفات المختارة مع أحجامها وحالتها، واختيار المادة تلقائياً.

3. **إصلاح عرض النصوص والخطوط العربية في ملفات الـ PDF:**
   - حل مشكلة تفكك الكلمات العربية وتحولها إلى حروف مقطعة: اعتماد العارض الأصلي للمتصفح (`Native Browser Engine`) افتراضياً، والذي يستعين بمحرك تشكيل الحروف المدمج بالنظام لتقديم خط عربي سليم 100% مع تشكيل الحروف والرموز الرياضية.
   - تزويد وضع الصفحات (`PDF.js`) بخرائط الحروف الكاملة (`cMaps` و `standardFontDataUrl`) لمنع تشوه النصوص العربية عند التصفح صفحة بصفحة.

4. **إدارة المواد والوحدات والملفات (من المرحلة الثانية):**
   - إدارة المواد والفصول والوحدات مع حذف تسلسلي آمن.
   - حفظ الملفات الثنائية محلياً كـ `Blob` في `IndexedDB` دون Base64 وبدون خادم خارجي.
   - تصدير واستيراد النسخ الاحتياطية المضغوطة بصيغة `.unistudy.zip`.

## 🛠 التقنيات المستخدمة

- **الواجهة:** React 19 + TypeScript + Vite.
- **التصميم:** Tailwind CSS v4 مع دعم كامل للغة العربية (RTL) والوضع الفاتح/الداكن.
- **التخزين المحلي:** IndexedDB مع `Dexie.js` و `dexie-react-hooks`.
- **معالجة المستندات والضغط:** `pdfjs-dist` + `JSZip`.
- **الأيقونات:** `lucide-react`.
- **الاختبارات:** Vitest + React Testing Library + `fake-indexeddb`.

## النشر على Vercel

1. استورد المستودع في Vercel (Framework Preset = Vite؛ الإعدادات تُقرأ من `vercel.json`).
2. المحتوى المشترك (اختياري لكنه ما يجعل التحديثات تصل للجميع):
   - من Vercel ← Storage ← أضف **Upstash Redis** واربطه بالمشروع (يضيف متغيرات `KV_REST_API_URL` و`KV_REST_API_TOKEN` تلقائياً).
   - أضف متغير `ADMIN_KEY` بقيمة سرية من اختيارك، ثم أعد النشر (Redeploy).
3. الاستخدام: افتح الموقع ← الإعدادات ← «أدوات النشر» ← اختر المواد ← أدخل `ADMIN_KEY` ← «نشر للجميع».
   أي مستخدم يفتح المنصة يحصل تلقائياً على آخر محتوى (منهج وأسئلة). النتائج والتقدم الشخصي تبقى على جهاز كل مستخدم.
4. بدون إعداد Redis تعمل المنصة محلياً بالكامل ويمكن استيراد المحتوى من نسخة احتياطية.

## ملاحظات
- لا يوجد نظام حسابات (تسجيل دخول): الجميع يقرؤون المحتوى المشترك نفسه. ملفات PDF لا تُنشر ولا تُرفع، وتبقى محلية.
- لا توجد ميزات ذكاء اصطناعي في المنصة.
